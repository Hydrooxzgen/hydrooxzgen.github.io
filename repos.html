API 设置

前往 GitHub Token 设置 创建一个 Fine-grained Token
权限只需勾选 Read-only 的 Contents（用于读取 README）
未设置 Token 时，未登录状态 API 限制为 60 次/小时；设置后为 5000 次/小时

🔒 安全说明：Token 仅保存在你浏览器的 localStorage 中，不会上传到任何服务器。
每次 API 请求仅发送到 api.github.com。
如不放心，可随时点击「清除 Token」删除。
