项目简介

CanApp 是一个开箱即用的 Windows 桌面应用合集，将多个实用小工具整合到一个简洁的图形界面中。 项目基于 Python 标准库 Tkinter 开发，无需复杂的运行时环境，内置 多语言支持（简体中文 / 繁体中文 / English）与本地用户系统， 界面文字可实时切换刷新，适合日常快速调用的桌面场景。

核心特性

  • 基于 Tkinter 的轻量图形界面，单文件主程序，开箱即用
  • 内置简中 / 繁中 / 英文三语切换，界面文字实时刷新
  • 本地用户系统，用户数据存储于本机 UserFiles 目录
  • 整合多种实用小工具，随取随用
  • 提供 PyInstaller 打包脚本与 Inno Setup 安装包脚本
  • 内置测试套件与 i18n 校验工具，保证翻译键同步

多语言支持

内置三语切换，语言文件位于 lang/ 目录，格式为 JSON：

语言代码 语言 说明
zh_CN 简体中文 默认语言
zh_TW 繁體中文 繁体中文
en_US English 英语

安装与使用

1

方式一：安装包（推荐）

前往 GitHub Releases 下载 CanApp_Setup_x.x.x.exe，双击安装即可。仅支持 Windows 系统。

2

方式二：从源码运行

需要 Python 3.13+（自带 Tkinter）：

# 安装依赖
py -m pip install requests pythonping

# 运行
py CanApp.py

项目结构

CanApp/
├── CanApp.py # 主程序（单文件应用）
├── CanApp.spec # PyInstaller 打包配置
├── CanApp_installer.iss # Inno Setup 安装脚本
├── lang/ # 多语言翻译（JSON）
│ ├── zh_CN.json # 简中翻译（默认）
│ ├── zh_TW.json # 繁中翻译
│ └── en_US.json # 英语翻译
├── UserFiles/ # 用户数据（运行时生成）
├── dev/ # 测试与调试工具
└── how_to_releaseArelease.txt # 发布流程
